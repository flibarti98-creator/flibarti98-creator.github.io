// WORKFLOW — JAK PRACUJĘ Z GIT

01.
Checkout gałęzi developerskiej: git checkout develop
02.
Tworzę nową gałąź funkcjonalności: git checkout -b feature-nazwa
03.
Implementuję kod (HTML, CSS, JS).
04.
Zatwierdzam zmiany: git add . && git commit -m "feat: opis"
05.
Push do zdalnego repo: git push origin feature-nazwa
06.
Tworzę Pull Request do gałęzi develop na GitHub → Code Review → Merge (Create a merge commit)
